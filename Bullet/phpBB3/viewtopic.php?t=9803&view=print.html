Hi all. Info on my indie game using Bullet!

I've launched my small indie RPG game on Kickstarter:
https://www.kickstarter.com/projects/61 ... ilicon-rpg

Take a look at the project page for info but basically I'm using Bullet bullet-2.81-rev2613 with multi-threading. Setting up to use multi-threads/multi-cores wasn't too bad but I spent quite a bit of time tweaking the physics parameters for the character controller in order to get something that works OK with my models. I also have soft-body and buoyancy (water) support and support for fracturing (breaking) models into pieces.

Thanks!
