Bullet 2.19a released

Posted: Sat Oct 28, 2006 2:45 am
by Erwin Coumans
New in Bullet 2.19a:

* better solver performance (caching the impulse arm/cross product)
* more generic concave support, uses the registered collision algorithm by using the dispatcher
* added back the safety catch in GJK for uninitialized transforms
* comparison algorithms: dedicated SphereTriangle, and in Extras/AlternativeCollisionAlgorithms the ODE box-box
* recompiled the C4 graphics engine integration (win32) for Bullet 2.19a
