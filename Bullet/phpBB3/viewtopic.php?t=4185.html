automake --disable-extras option (patch included)

  • Quote

Post by mikedilger » Mon Oct 12, 2009 12:00 am

I created a patch to build bullet without the extras from autoconf/automake. This is useful for some systems without GL that just want the basics (e.g. collision detection on a headless server). It adds --disable-extras option, but leaves extras on by default.

It also rearranges autogen.sh which looked backwards to me, but maybe I'm crazy so skip that part if I am. And it removes some spurious whitespace.

This is against 2.75

phpBB isn't letting me attach the file (even renamed with .txt), so here it is in base64:

Code: Select all

   base64 -d FILEYOUSAVED > bullet-2.75-build-extras.patch
   cd bullet-2.75
   patch -p1 < ../bullet-2.75-build-extras.patch
