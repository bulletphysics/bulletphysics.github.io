Hi Erwin,

Here are a few bugs in Blender that were found when taking the GE course last week ( the students loved the Bullet physics btw! )

I've included a brief description, as well as a .blend file ( which contains more info on the bug )

1) Incorrect results when setting the linV property within the Movement sensor
http://www.candointeractive.com/blender ... linV.blend

2) Issues with sleeping objects and applying forces/torques
http://www.candointeractive.com/blender ... ping.blend

3) Message sensor seems to be sending twice
http://www.candointeractive.com/blender ... sage.blend

This is more of a feature request, to have the Blender physics within Blender automatically use the Scaling. This will make Blender / Bullet a LOT easier to use - resetting the scaling on a scaled object can make a huge difference to how a Bullet scene reacts, but is something that new Blender users may not realise how to do ( or why it is necessary ) and experienced users can forget to do it also.

http://www.candointeractive.com/blender ... ling.blend

I hope the simple .blend files help explain what's happening, and the bug fixing helps improve the future version of Blender GE!
