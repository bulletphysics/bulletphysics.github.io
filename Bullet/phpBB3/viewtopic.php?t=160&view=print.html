Novodex for Maya - Beta 3

Posted: Mon Oct 31, 2005 7:52 pm
by claforte
Feeling Software is pleased to announce that Beta 3 of Nima (Novodex for Maya) is now available for download on our web site:

http://www.feelingsoftware.com/index.ph ... 67&lang=en

Changes from Beta 2 to Beta 3
- Ragdoll construction scripts have been added, along with numerous resources to demonstrate ragdoll construction, including movies and the orc example scene. These scripts allow creating a ragdoll from a skinned character.
- Updated from Novodex 2.2 to Novodex 2.3. The solver is now more robust, eliminating some problems with rigid bodies ?exploding? mysteriously. Note that the Novodex 2.3 library that ships with Nima is an unnofficial build, that has been slightly modified to correct a problem with visualization not updating immediately.
- Exposed solver iteration count on rigid bodies, since the default value (4) is generally not sufficient for complex systems (e.g. ragdolls).
- Many minor features and bug fixes, such as ?Select All Novodex Rigid Bodies?, ?Select All Novodex Rigid Constraints?, ?-name? parameter now working when creating rigid bodies and constraints, etc.

Note that we are aware of one problem with the ragdoll skinning: the skinning on ragdoll tends to flip. Unfortunately, at this time I am unable to provide an estimate of when this problem will be fixed, since it will require working around Maya limitations related to parentConstraint and skinning.

We are also putting the finishing touches on the Collada export of Nima physics. The official ColladaMaya build this coming Thursday will include export of common-profile features.

Your feedback is appreciated by Feeling Software and Ageia. Please let us know if you use or plan to use Nima and/or Collada Physics. Future developments will depend on your feedback.
