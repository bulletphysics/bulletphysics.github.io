It is not a bug: Switch on 'Rigidbody' and it will work.

Basically, when enabling only 'dynamic', without 'rigidbody', it will create a rigidbody with a special hinge constraint (rotational only) that allows only rotation along the z axis. It was meant to be a bit backwards compatible with Sumo.
