Posted: Wed Oct 18, 2006 4:48 am

Bullet 2.17 is out:

Main features: uses btMotionState to synchronize interpolated worldtransform for 'realtime' simulation. you can specify the maximum number of substeps, so slow machines will clamp/drop frames.

See CcdPhysicsDemo for the effect: press 'i' and then 's' for single step/interpolation (interpolation means no simulation).
