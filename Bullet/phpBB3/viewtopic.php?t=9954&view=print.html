The Bullet Physics SDK source code repository is now located at github: http://github.com/bulletphysics/bullet3
I am preparing an initial Bullet 2.83 version from that repo, please clone and test the code and discuss in this forum if there are serious issues.

You can clone using either git or subversion/svn:

git clone http://github.com/bulletphysics/bullet3
svn co http://github.com/bulletphysics/bullet3/trunk bullet3

This year we are migrating toward Bullet 3.x. The Bullet 2.x API will be maintained during this year, while we are developing the Bullet 3.x API.
Thanks and enjoy!
Erwin
