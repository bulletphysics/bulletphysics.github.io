When doing the first, small version of the machine everythin worked.

Now, as I expanded the machine, the IPO Recorder deletes some of my dynamic objects as soon as the IPO baking finishes. Everything works, as long as I just do the realtime simulation, only the IPO baking is affected.

If I remove some of the objects before doing the IPO baking, the remaining are handled right.

What happened is you baked into IPO, cleared IPO, then baked again, multiple objects had the same IPO, bad.

Unfoutunatly, you need to delete any objects that you made after the first bake into ipo test. Then, follow the image's instructions every time you start up blender and you will be safe to duplicate oblects (just clear the ipo's first).
