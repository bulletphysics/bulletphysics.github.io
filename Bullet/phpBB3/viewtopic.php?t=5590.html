Post by Dragonlord » Wed Sep 01, 2010 6:08 pm

Looks like CMake doesn't link against libpthreads ( link flags: -lpthread ). Your CMake output doesn't contain though the actually commands invoked so it's impossible to see what goes wrong. But it's definitely symbol resolve error so CMake missed pthreads for one reason or the other. Have you installed lib6-dev? If not the library file required for linking will be missing and CMake will not be able to pick it up.
