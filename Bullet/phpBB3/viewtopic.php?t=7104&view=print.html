Physics Programmer at Rockstar Games

Posted: Wed Jul 20, 2011 8:12 pm
by RockstarGames
Rockstar Toronto is currently looking for a Physics Programmer to help us develop exciting physical simulations using our world class proprietary game engine. This programmer will be responsible for the game-specific application of physics elements such as ragdolls, biomechanical animation, vehicle dynamics, cloth, fragments, collisions, contact forces, fluid-dynamics, etc. We urge you to apply if you are seriously into games and want to work with the best in the industry.

Required:
3+ years of game programming experience with an emphasis on physics
Experience on Xbox360 or PS3
Excellent C++ skills
Superior 3D math skills

Desired:
Experience with commercial game physics SDKs
Experience writing physics simulation code
Knowledge of game physics algorithms
Experience with multithreaded/SPU programming
Credit on a shipped AAA game
Passion for playing and making great games
Bachelor's Degree in Computer Science, Engineering, or Physics

Rockstar offers a competitive salary and benefits package and a great work environment.
This is a full-time onsite position.
Please go to http://jobs.rockstargames.com/
Select the red logo (Toronto), and submit your resume and cover letter from there.
