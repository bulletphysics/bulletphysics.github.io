Hi,
you can use while loop to accelerate the bot in a way you want.
For example,

Code: Select all

while True:
    cubePos, cubeOrn = p.getBasePositionAndOrientation(bot)
    cubeEuler = p.getEulerFromQuaternion(cubeOrn)  
    dv = k*cubeEuler[0]
   p.stepSimulation()
Hope this helps!!!
