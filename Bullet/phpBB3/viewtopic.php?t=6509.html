EDIT: SOLVED IT!!!

The header guard in RigidBody.h conflicted with your header guards Erwin.

Code: Select all

#ifndef RIGIDBODY_H
#define RIGIDBODY_H

class RigidBody{};

#endif
That conflicts with the header guard in btRigidBody.h
