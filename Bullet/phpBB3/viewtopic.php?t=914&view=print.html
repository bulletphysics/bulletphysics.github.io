yes, when creating a new gear...

1. The things connected to the cylinder need to be fix up first

2. Create the cylinder, add the constraints.(object buttons F7, add constraint, select hinge constraint, hit "show pivot", the hinge pivots on the px axis)

3. In the cylinders logic buttons Select "compound"

4. Add a cube

5. Set the bounds of cube to cube

6. On the cube use alt-r then ctrl-a then alt-p(clear the "clear parent inverse" do this BEFORE parenting it to the cylinder.

7. Parent the cube to the cylinder

hope that works.. and helps
