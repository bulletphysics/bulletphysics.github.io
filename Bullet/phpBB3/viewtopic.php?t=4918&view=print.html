Call for Papers -- Game Engine Gems 2

Posted: Wed Mar 31, 2010 10:55 pm
by Eric Lengyel
After a very successful launch of the first volume of the Game Engine Gems series at GDC 2010, Jones and Bartlett Publishers is now accepting proposals for the second volume! The paper submission period for Game Engine Gems 2 is now open through June 15, 2010. To submit a proposal, please visit the official website at the following location:

http://www.gameenginegems.net/

As with the first volume, the theme of the book includes everything having to do with game engine design and implementation. Specific topics that we're looking for include rendering techniques, shaders, OpenGL / DirectX, physics / collision detection, mathematics, programming techniques, engine architecture, visibility determination, audio, user interface, input devices, memory management, artificial intelligence, resource organization, and cross-platform considerations. This list is not exhaustive, and we will be happy to evaluate any idea that pertains to making game engines.

The schedule for Game Engine Gems 2 is as follows.

June 15, 2010 -- Final day to submit article proposals. Authors notified of acceptance.
Sep 1, 2010 -- Final day to submit completed article drafts. Editing process begins.
Oct 15, 2010 -- Editing completed and manuscript finalized.
Dec 15, 2010 -- Book production completed, sent to printer.
Game Developers Conference, 2011 -- Book released!

If you have any questions or would like feedback before making a submission, please don't hesitate to contact the series editor, Eric Lengyel, at lengyel@terathon.com.
