Oh never mind, I solved my issue. After performing all the steps mentioned previously in this thread, I did the following:

1) I use MSVS 2010 x64, so I had cMake build the libraries using the MSVS 2010 64 bit generator. But, while making the BulletTestApp project, I chose the target platform as Win32. I changed the target platform to x64 for BulletTestApp.

2) I went to BulletTestApp (Right Click on the project name) -> Add -> Existing Item. Then I added BulletCollision.lib, BulletDynamicslib and LinearMath.lib to the project.
