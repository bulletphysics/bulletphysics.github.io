Yes, COLLADA 1.5 contains support for kinematics and articulated systems. This seems particularly useful for physics simulation. There exists a plugin for SolidWorks that allows one to export to COLLADA 1.5 (http://labs.solidworks.com/Products/Pro ... ladaexport). I don't know of any other authoring tools programs that support 1.5 yet, but hopefully others will offer this as well in the near future.
