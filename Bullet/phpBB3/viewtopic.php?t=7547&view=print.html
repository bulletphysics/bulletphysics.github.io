Ships!

Posted: Wed Oct 19, 2011 4:12 am
by squisher
Hi All!

I'm very excited to announce the release of a project I've been working on as a hobby for quite some time now. It's an action MMO shooter set in space, and it's FREE to play. Check it out: http://squisher.co/ships

The game uses four awesome open source engines: IrrLicht, IrrKlang, RakNet, and Bullet. This project is my way of saying thank you to everyone who volunteers their time to work on those engines. It's also my way of having a whole lot of fun!

Ships is in its infancy. It's still missing about 95% of the content I'm planning to add. My goal was to get it to a playable complete game as soon as possible, release it, and then start adding in additional content afterwards.

Please post any responses you'd like me to see on the forum of the Ships website, http://squisher.co/ships
