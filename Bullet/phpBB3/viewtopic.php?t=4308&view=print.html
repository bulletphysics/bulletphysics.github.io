Announcing osgBullet

Posted: Wed Nov 11, 2009 5:18 pm
by PaulMartz
Hi all -- I'm pleased to announce osgBullet, a new open source Bullet-based project, licensed under LGPL. This is an active project with a discussion group, source download, wiki, and issue tracking. It is actively used by the open source VE-Suite application. It is funded by Ames Laboratory and created primarily by myself / Skew Matrix Software.

osgBullet is a set of software tools for applications that use both OpenSceneGraph and Bullet. It features utilities to create Bullet collision shapes from OSG data and vice versa, run the physics simulation in a separate host thread, debug utilities to display Bullet collision shapes in an OSG scene, support for arbitrary scaling and center of mass, and support for COLLADA.

For more information on osgBullet and to download the source, visit:
http://osgbullet.vesuite.org

For questions, please post to the project discussion group hosted on Google Groups.
