The best bet right now is Blender, it has Bullet integrated and allows to setup collision shapes, rigid body and constraints, as well as run the simulation.
There are some books on how to use Bullet inside Blender with examples, such as 'bounce, tumble and splash' by Tony Mullen.

The Dynamica Maya plugin can do the same, except for constraint support (it is work-in-progress).
What kind of editor do you have in mind? Which platform?
