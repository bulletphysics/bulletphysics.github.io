Dear All,

I'm a newbie at all of this, but I can't work out what to do next.

I'm running Ubuntu 10.04 with an ATI graphics card, and this is my first attempt at compiling something rather than installing a .deb file.

Have followed instructions from http://www.icram.de/content/compileinst ... -910-howto (but didn't run sudo make install) which seems to be similar to other instructions I've seen for compiling Bullet.

I've tried a couple of versions...
2.76 failed to make, quitting at 99% stage
2.77 seemed to make correctly barring warnings of depreciation of chars

When I first tried to run the 2.77 AppAllBulletDemos it would run, but I was unable to see menu area which was grey. This appeared to be solved by altering the Visual Effects in the Appearance settings to None (from Normal). Now the app would run fine, and clicking on the Next Scene button would cycle correctly up until I reached the SoftBody Cluster Collide1 test. It will then automatically run a trial for 3 or so seconds and then run the next one. The iconic rabbit car never reaches the bottom of the steps (my real complaint). It cycles back to the Cluster Collide1 test and repeats. This behaviour also occurs if I use the menu to select (say) the Cluster Car.

Any ideas as to whats causing this and how to correct it?
