Is there possibiliti to create composite shapes im Bullet?
Just like MultiSphereShape but from any shape.
You can do the Minkowski sum and convex hull of other shapetypes.
But there is not a concave composite shape yet. It is on the todo list, combined inertia needs to be calculated.
Another questions, is there Capsule shape?
Yes, you can create a capsule from 2 spheres, using the MultiSphereShape.
