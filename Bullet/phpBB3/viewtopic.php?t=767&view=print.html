Hi.
I will try to explain it with an example. Also consider that this is how I understand it and I am not sure if it is right.
Lets say that you have tow cubes. You have placed them in the proper position and you wand to create a hing. To find the right values for the hing you can enter the edit mode. In there choose the edge you wand for the hinge. Press N and see the values. For example in the default cube the up-left edge have the values : Median x : -1.0 , y : 0.0 , z : 1.0. So if you wand the hinge to be placed on this edge you must set the Pivot values as the median values of the edge. Note that those values are in the midle of the edgw so here comes the Ax values of the constraint. The Ax are the values that tell the hinge how long it is and in wich Axis is placed. So back in the example you must set the Ax y to 1.0 .
