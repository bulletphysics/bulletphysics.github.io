osgBullet v2.0 now available (release notes, video)

Posted: Tue Nov 08, 2011 3:11 am
by PaulMartz
osgBullet v2.0 is now available!

osgBullet is a set of software tools for applications that use both OpenSceneGraph (OSG) and Bullet. Like OSG and Bullet, osgBullet is cross-platform C++ F/OSS, and available for use under LGPL. osgBullet was the recipient of a 2010 R&D 100 award.

v2.0 is the first major revision to osgBullet since its inception, and features a reorganized library structure, new osgGA-based event handlers for mouse interaction with scene elements, complete Doxygen documentation, and a cleaner, easier-to-use API. Full release notes are at the Google Code project page.
