Tiny and Big - Up That Mountain

Posted: Fri Mar 12, 2010 7:11 pm
by tinyandbig
We just published the first beta of our game "Tiny and Big - Up That Mountain". All in all, we worked around 7 months on this release. The game is based on our own game engine called scape.

It uses the Bullet physics engine for simulating dynamic bodies (mainly convex meshes), collision detection and ragdolls. Especially the soft body feature worked great for creating the realistic rope that Tiny uses.

You can download the game at http://www.tinyandbig.com/download.

There already are some neat videos of the game and the physics online.
