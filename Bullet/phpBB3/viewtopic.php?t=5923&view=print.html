Bullet Physics Now in Browsers

Posted: Sat Nov 06, 2010 7:25 pm
by tleave2000
A web browser plugin for the Blender Game Engine has just brought Bullet into web browsers. I don't think I've heard of this kinda thing before, and it's super fun.

The warning is that the plugin hasn't been sandboxed yet, so you should disable it when visiting sites you don't trust.

If anyone has any good ideas about security, contributions are welcome. It's all open source so just make yourself known at the Burster website below. It'd be great to get that aspect sorted as it would really make this into a Flash killer.

Here's the Burster website : http://geta3d.com/index.php?option=com_ ... &Itemid=19

Here's a physicsy demo page with a YouTube video for people who don't want to download the actual plugin: http://www.tobedesign.co.uk/boxapocalypse/
