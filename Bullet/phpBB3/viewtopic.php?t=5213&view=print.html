I ran into the same problem with the missing options file, but it does not prevent you from exporting. I think maybe yaoyansi is attempting to export by clicking the Square icon on the right of Export All and Export Selction in the file menu, which attempts to directly invoke the exporter options. If you just select the text portion of Export All or Export Selection you can select Bullet Physics as your file type and successfully export.

Also only the 2008 version of Dynamic installs to a 2.76 directory name instead of 2.77 like the other versions.
