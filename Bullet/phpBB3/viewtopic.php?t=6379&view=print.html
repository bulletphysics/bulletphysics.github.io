Aordee - virtual robot design and simulation

Posted: Sun Feb 20, 2011 8:10 pm
by darus
Hi!

I've just released a 1.0 version of Aordee, a software for fast and easy creation of robots and mechanisms. With Aordee, you can assemble a robot from a set of components and create an algorithm for moving it using a diagram-based programming language.

Aordee uses an unmodified version of Bullet Physics. Physics engine works really great, thanks to the creators of BulletPhysics! You can download the software, and check the 'hexapod' sample for a demo of 6-legged robot with 12 engines - it's a fun!
