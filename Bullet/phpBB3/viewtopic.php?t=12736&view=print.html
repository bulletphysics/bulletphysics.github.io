Hi! Not sure you'll read this since your post is 1 month old, but anyway:

I'm working on a freeform robot building game that uses bullet physics too! There was this robot game that had a following around 2013, but the devs abandoned it. A small group of players stayed regardless, and happily for us, the source code was retrieved this year. We're considering going open source.

Your game looks quite polished. Do you plan to have modding support? I don't know how compatible unreal engine is with modding, but an interesting thing about our fanbase is that the most dedicated players all have at least a modicum of programming ability. Our most prolific member modded the game via msil (already compiled c#) even back before we had source code access. I'm leading the development mostly because I'm the one with the most free time.

Your type of game attracts technical people. This helps for mods, just look how large kerbal space program's modding scene is.

Also, I think you have implemented networked physics for an online multiplayer mode? Thats really cool! Did you do that from scratch?

On one hand, part of me is disappointed that our amateur effort will likely be overshadowed now that a pro dev team is targeting the same niche. On the other hand,our fanbase has been hungry for a game like yours since a long time. I'm excited for them and wishes your team good luck.
