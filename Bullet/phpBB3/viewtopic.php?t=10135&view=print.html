Posted: Mon Sep 29, 2014 12:33 pm

Hi!

Uncrewed is an RTS with the ability to design your own units. Another defining feature of the game is that the units are actual physical entities (they can collide, get stuck on rough terrain, float, sink, etc.)

The game uses the Bullet Physics Library (including rigid body dynamics, collision detection, ray casting).
