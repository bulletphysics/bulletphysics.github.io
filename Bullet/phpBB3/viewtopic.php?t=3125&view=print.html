I have posted a new version of DANCE with updated code at:

http://www.magix.ucla.edu/dance/#download

The new version is: dance_v4_012109.zip

DANCE is a software package for physics-based character animation. One of its goals is to provide researchers with a common platform where they can test their control methods and share their results. In addition, it provides the common, yet complex functionality that everyone needs in a physics-based animation system, allowing researchers to concentrate on their research work. DANCE has been used for a variety of physics-based applications that include biomechanics modelling and composeable controllers.

This version contains:

1) Builds on Window, Linux, OsX
2) Scriptable controllers (use Python to write controllers)
3) Non-linear editor for controllers
4) Attachments
5) Some bug fixes
6) Updated manual

I appreciate any feedback about making sure that the code
builds and runs properly.
