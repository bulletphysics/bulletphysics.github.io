Game we used to play when we were kids - Chapaev (http://en.wikipedia.org/wiki/Chapayev_(game). After getting tired of thinking (playing real checkers), lined up the pegs, flexed our fingers, and start flicking/shooting pegs trying to knock each others pegs off the board.

The core of the game is a slightly optimized Bullet (as part of Oolong Engine by Wolfgang Engel). Kudos to Erwin! Every single place that needed to be modified was already either a virtual function, or otherwise "hookable".

In addition to classic gameplay, over 30 different layouts were added.

I have the same feeling about Bullet as I had about SQLite (long before it's current dominating position on all platforms).
