Thanks for the feedback.
Some dll's should be copied in the Maya/bin folder indeed:
glew32.dll
GLUT32.dll
msvcp80.dll
msvcr80.dll
and the other in the bin\plugins folder:
BulletMayaPlugin.dll

Can you try out the updated Dynamica plugin revision 3, and see if that works for you?

Has anyone experience writing an installer for a Maya plugin, such as Windows Installer .msi or NSIS http://nsis.sourceforge.net/Main_Page?
Thanks,
Erwin

By the way, if all this fails, you could try to to load the BulletMayaPlugin.dll in dependency walker (http://www.dependencywalker.com) and see what is missing (ignore MSJava.dll).
