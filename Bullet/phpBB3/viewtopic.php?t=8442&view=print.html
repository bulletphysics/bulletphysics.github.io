I would recommend to install the newer Dynamica for Bullet 2.81 installers from
https://code.google.com/p/bullet/downloads/list

The sample scenes are installed by the installer, just click the Windows START button to All Programs/Dynamica Bullet/Examples.
By default the example Maya scenes are located here: (replace the path with your Maya version)
C:\Program Files\DynamicaBullet2.81ForMaya2012-x64\scenes
