FPS Creator Reloaded uses Bullet Physics!

Posted: Mon Jan 06, 2014 11:19 am
by rvanner
Hi,

Our new First Person Shooter tool (FPS Creator Reloaded) uses Bullet Physics for it's core physics engine. We chose Bullet for many reasons - great performance, device independent, free to use on PC and we'd just heard good things about it.

So far we have used Bullet for the character controller, dynamic objects, static objects and height field terrain.

The project is in early Beta. It will develop significantly over the next few months now that the core engine is in place.

You can read more about FPS Creator Reloaded on our website www.fpscreator.com
