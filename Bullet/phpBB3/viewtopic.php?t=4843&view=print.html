iShuffleGame

Posted: Mon Mar 15, 2010 7:25 pm
by TatamiSoftware
Hi Everyone,

I am proud to announce the release of our first game for the iPhone, iPad and iPod Touch platforms, iShuffleGame. This is an implementation of a deck shuffleboard game in which users launch their discs using the accelerometer to create realistic game play. Visit iShuffleGame.com or look for us on iTunes for more information.

We used the bullet-2.75 library as the core physics engine, which gave the game smooth, realistic physics with minimal effort.

I would like to thank all of the developers and members of these forums for helping this game come to life.
